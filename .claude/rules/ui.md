# UI Design Principles

1. シンプルにする（要素を増やさない）
2. 簡単にする（手順を減らす）
3. メンタルモデルに合わせる
4. シグニファイア（押せそう/押せなさそうを明確に）
5. 一貫性（同じものは同じ表現・挙動）
6. ユーザーの言葉を使う（専門用語を避ける）
7. ユーザーの記憶に頼らない（その場で参照できる）
8. エラーを回避する（起きない設計 + 建設的メッセージ）
9. 可逆性（戻せる/取り消せる）
10. メジャータスク最適化（80%に合わせる）

## UI変更時
- 先に state を列挙する: idle / loading / loaded / empty / error
- エラーは「次に何をすればいいか」が分かる文言にする
- 入力にはバリデーションと建設的メッセージを用意する

## UI変更の完了条件
- 主要 state（loading/empty/error）を確認済み
- 文言がユーザーの言葉で一貫している
- 可逆性（取り消し/戻る）を壊していない
- アクセシビリティ最低限: タップ領域 / ラベル
